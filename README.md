# Ransomware Detection Engine

An AI-powered hybrid ransomware detection project using supervised machine learning and unsupervised anomaly detection. The complete source project is included in `Hybrid-Ransomware-Detection.zip`.

## Contents
- Training and evaluation pipeline
- Feature engineering and preprocessing
- Hybrid supervised + Isolation Forest detection
- Prediction CLI and Streamlit dashboard

See the project archive for installation and usage instructions. Dataset files and trained model artifacts are not included; add the required datasets locally before training.
